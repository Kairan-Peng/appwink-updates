## AppWink Updates

This repository hosts the public Sparkle update feed and signed release assets for [AppWink](https://github.com/Kairan-Peng/AppWink).

Published content:

- `appcast.xml`
- `downloads/`
- `release-notes/`
- `license/appwink-license-endpoints.json` for legacy clients only

Release downloads are signed and notarized. New update entries retain the existing Sparkle public key. The 0.1.45 publication keeps the previous 0.1.42 installer and notes available at their existing URLs; any future pruning requires a separate retention decision.

Current AppWink releases are free GPL-3.0-or-later software and require no trial, activation or license server. The legacy endpoint-discovery file remains unchanged for older clients; it is not used by current releases.
