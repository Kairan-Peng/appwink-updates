AppWink 0.1.32 Release Notes

AppWink v0.1.32

This release fixes several Settings and hotkey-list polish issues: localized target app names now follow the selected AppWink language, Follow System correctly resolves Simplified Chinese macOS systems, shortcut recorder hover state no longer sticks after row/window changes, Hidden Bar uses matching arrow affordances, and the Activity Monitor feature now appears as a managed fixed hotkey row in the hotkey configuration list.

Existing app bindings, shortcut assignments, direct-license state, Sparkle update settings, and saved utility preferences remain compatible with 0.1.31.
