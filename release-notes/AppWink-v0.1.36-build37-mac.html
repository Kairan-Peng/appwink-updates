AppWink v0.1.36

This release refines the Network Monitor status item and the shared feature detail header layout.

What's New

  • Reduced the Network Monitor status-item width from 68pt to 56pt for tighter menu-bar spacing.
  • Aligned both speed lines around one shared boundary: numeric values are right-aligned in a 28pt column, followed by a 2pt gap, while units are left-aligned in a 26pt column.
  • Kept the unitless -- fallback centered across the full status-item width.
  • Vertically centered the icon against the complete description text on all eight Settings feature detail pages, including wrapped summaries.

Install Notes

  • Existing users can install 0.1.36 in place over 0.1.35 from the formal notarized DMG.
  • The update is designed to preserve existing bindings, preferences, direct-license state, and saved utility settings.
  • Network Monitor remains opt-in and requires no new permission.

Known Limitations

  • Network Monitor continues to read only the current system-selected primary interface; it does not aggregate interfaces or detect VPN state.
  • The compact fixed columns cover the representative 100.0 MB/s boundary used by the current formatter and fonts. Arbitrarily longer future formatter output is outside that fixed-width guarantee.
  • A fresh visual pass of the final shared-column geometry was NOT RUN because the Mac was locked. The renderer geometry and actual AppKit draw operations are covered by automated tests; the preceding isolated pass already verified the 56pt width and all eight vertically centered feature descriptions.
  • Light and increased-contrast menu bars, a real notched display, Command-drag/relaunch ordering, Hidden Bar pusher-left interaction, physical interface switching, disconnect/reconnect, sleep/wake, temporary reader failure, and entitlement loss/restore remain NOT RUN rather than passed.
