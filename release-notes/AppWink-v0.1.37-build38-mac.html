AppWink v0.1.37

This release expands global hotkeys beyond applications so selected folders and files can be opened directly.

What's New

  • Added one unified Add / 添加 flow for applications, ordinary folders, files, and document packages.
  • Kept application hotkeys on the existing activate/hide toggle while adding configurable opening modes for folders and files.
  • Added Finder (New Tab) as the default folder action, current system default as the default file action, and optional selected-application handlers for both folders and files.
  • Added bookmark-backed target persistence, opening-mode-aware duplicate handling, and target-aware menu, quick-switch, virtual-keyboard, and icon presentation.
  • Limited Accessibility and Finder Automation requirements to actions that actually need them.

Install Notes

  • Existing users can install 0.1.37 in place over 0.1.36; existing application bindings, shortcuts, ordering, preferences, and license state are designed to migrate without manual reconfiguration.
  • Opening a folder with Finder (New Tab) requires Accessibility and may show macOS's one-time Finder Automation consent prompt. File bindings and folders opened with a selected application do not require those permissions.

Known Limitations

  • If a Finder browser window is minimized and its folder hotkey is triggered immediately, macOS may temporarily omit that window from Accessibility. AppWink then opens the selected folder in a separate Finder window instead of adding a tab to the minimized window; the original tabs remain unchanged.
  • The final implementation's no-window, pre-existing matching-tab, rapid-repeat, permission-revoke/restore, unavailable-target/handler, dynamic default-handler change, and full presentation matrix were not all rerun manually. Automated coverage and the recorded unlocked Direct QA cover the main configuration, file, selected-handler, bookmark, persistence, and Finder foreground/background paths.
  • The Mac App Store build shape includes a Finder-only temporary Apple Events exception, but local signing and packaging do not constitute App Review acceptance. This release publishes the Direct notarized DMG only.
