AppWink v0.1.38

This release makes folder opening feel native, simplifies transfer-rate output, and gives file/folder opening modes a more compact presentation.

What's New

  • Default folder hotkeys now use macOS's public system-open behavior, matching the boundary of double-clicking a folder in Finder. Finder decides whether to reuse a window, open a new window or tab, and switch Space.
  • Removed the visible Finder menu/new-tab automation sequence and its Accessibility, Finder Automation, Apple Events usage-description, and Apple Events entitlement requirements.
  • Moved each folder/file opening-mode selector onto the target-name row, immediately left of the shortcut, using a compact Finder/application icon, divider, and chevron that adapts to Light and Dark appearance.
  • Kept the native application menu, selected checkmarks, candidate icons, keyboard/accessibility behavior, and Choose Other Application... action.
  • Network Monitor now uses KB/s as its minimum unit. Very low transfer rates round to 0 KB/s instead of switching to B/s.

Install Notes

  • Existing users can install 0.1.38 in place over 0.1.37; bindings, shortcuts, opening modes, order, preferences, and license state are designed to remain compatible.
  • The stored folder-mode discriminator remains unchanged for configuration compatibility, but its runtime behavior is now the native macOS system-open request.
  • Default and selected-application folder actions and both file modes require no Finder Automation permission. Application activate/hide hotkeys continue to require Accessibility.

Known Limitations

  • Finder owns default-folder window/tab/Space behavior, so the exact visible result follows the user's Finder preferences and current desktop state.
  • Pointer-hover appearance, VoiceOver audio, a long file name combined with an unavailable badge, and a selected non-default handler were not rerun in the compact-selector manual pass.
  • The complete default-folder foreground/background/minimized/not-running/ cross-Space/rapid-repeat matrix and the installed Network Monitor live-unit GUI matrix were not fully rerun before this cut; automated dispatch, permission, formatting, and presentation coverage passed.
  • This release publishes the Direct notarized DMG only. MAS purchase/restore and App Store Connect evidence remain separate work; the former Finder Apple Events temporary-exception blocker no longer applies.

Verification Scope

  • Focused default-folder system-open, action-executor, target-model, AppModel/localization, Network Monitor formatting/controller, row-layout, presentation, and presentation-resolver suites
  • Signed Direct, production-shape MAS, and local StoreKit MAS package checks, including absence of NSAppleEventsUsageDescription, Apple Events automation, and Finder temporary-exception entitlements
  • Isolated minimum-width GUI/AX verification in Light and Dark appearance for folder/file row order, long-folder-name truncation, Finder/system-default icons, selected checkmarks, candidate applications, and final Choose Other Application...
