AppWink v0.1.40

This release refines the inline opening-mode selector for file and folder hotkeys.

What's New

  • The opening-mode selector no longer draws a thick blue native focus ring after pointer or keyboard activation.
  • Its idle and pointer-hover surface now uses the shortcut recorder's exact gradient, border, highlight, and subtle white glow treatment.
  • Keyboard traversal and Space/Return activation, the full-width pointer target, native application menu, and Choose Other Application... action remain available.

Install Notes

  • Existing users can install 0.1.40 in place over 0.1.39; bindings, shortcuts, opening modes, order, preferences, and license state remain compatible.
  • Folder opening continues to use macOS's public system-open behavior and file opening continues to resolve the current system default dynamically.

Known Limitations

  • Finder owns default-folder window, tab, reuse, and Space behavior.
  • VoiceOver audio and a long file name with an issue badge were not rerun for this focused visual patch; the native pop-up-button accessibility role, keyboard activation, and menu item semantics remain present.
  • This release publishes the Direct notarized DMG only. MAS purchase/restore and App Store Connect evidence remain separate work.

Verification Scope

  • Regression coverage for suppressing the native focus ring without removing keyboard focus or activation
  • Regression coverage locking the selector's idle and hover metrics to the shortcut recorder's non-recording states
  • Real pointer activation, native-menu cancellation, no-blue-ring inspection, and side-by-side selector/shortcut hover comparison
  • Confirmation that the existing Typora/Finder opening modes and ⌥J / ⌥D shortcuts were unchanged after UI verification
  • Focused swift test (13 tests, 0 failures), full swift test (609 tests, 0 failures), swift build, local package creation, and git diff --check
  • Packaging, signing, notarization, public-artifact, Sparkle-feed, and final installed-app checks remain part of the publication gate
