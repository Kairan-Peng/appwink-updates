AppWink v0.1.41

This release makes the inline file and folder opening control faster to use without giving up its opening-mode menu.

What's New

  • The control is now split into two independent actions: click the larger application icon to open the configured file or folder immediately, or click the chevron to choose a different opening application.
  • The icon and chevron halves highlight independently and use the same hover treatment as the adjacent shortcut recorder in both Light and Dark modes.
  • Keyboard and accessibility users now get distinct direct-open and Open With controls instead of one full-width pop-up button.
  • The native application menu, selected checkmark, candidate icons, and Choose Other Application... action remain unchanged.

Install Notes

  • Existing users can install 0.1.41 in place over 0.1.40; bindings, shortcuts, opening modes, order, preferences, and license state remain compatible.
  • The left icon uses the same binding execution path as the hotkey and menu-bar action. Folder opening therefore continues to use macOS public system-open behavior, while files continue to resolve the configured handler.

Known Limitations

  • Finder owns default-folder window, tab, reuse, and Space behavior.
  • VoiceOver audio, a long file name with an issue badge, and the complete Finder foreground/background/minimized/not-running/cross-Space matrix were not rerun for this focused control change.
  • This release publishes the Direct notarized DMG only. MAS purchase/restore and App Store Connect evidence remain separate work.

Verification Scope

  • Exact non-overlapping 40pt open and 32pt menu hit regions
  • Independent pointer, keyboard, accessibility, and hover dispatch
  • Native menu ordering, selection actions, and Choose Other Application...
  • Separate accessibility roles and localized direct-open descriptions
  • Follow System/Light and Dark real-pointer inspection of both hover halves, right-side menu presentation, and left-side Finder dispatch
  • Focused 33 tests, full 611 tests, swift build, local package creation, and git diff --check
