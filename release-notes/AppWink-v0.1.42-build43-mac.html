AppWink v0.1.42

This release adds flexible advanced shortcut recording and removes the retired Activity Monitor feature from Settings.

What's New

  • Settings now includes an Advanced Hotkeys switch. When enabled, shortcut recording accepts one or more of Command, Option, Control, and Shift with A–Z, 0–9, or ` - = [ ] ; ' , . / \ ``.
  • Default recording remains unchanged when Advanced Hotkeys is off: entering a bare letter or number automatically records it with Option.
  • Starting shortcut recording now suspends AppWink's registered global hotkeys. An existing shortcut such as Option-D can therefore be captured for another target without opening the target that already owns it. Current valid registrations are restored when recording ends or the window loses focus.
  • File and folder opening-mode controls now display their selected application icon at 28pt while preserving the split direct-open and menu actions.
  • The retired Activity Monitor managed feature has been removed from Settings. AppWink cleans up only its retired managed state and preserves ordinary Activity Monitor application bindings created by the user.
  • Advanced Hotkeys descriptions now state the modifier, key, and default-Option behavior precisely in both English and Simplified Chinese.

Install Notes

  • Existing users can install 0.1.42 in place over 0.1.41; bindings, shortcuts, opening modes, order, general preferences, and license state remain compatible.
  • Previously saved advanced shortcut combinations remain stored if Advanced Hotkeys is later disabled.
  • Folder and file hotkeys do not require Accessibility permission. macOS may separately request Files & Folders access when a protected location such as Downloads, Desktop, or Documents is opened for the first time.

Known Limitations

  • Advanced Hotkeys does not include the Fn key.
  • The exact real-input duplicate-capture case could not be completed through the local Computer Use bridge after its native click channel disconnected; the recorder lifecycle, Carbon suspension, queued-callback suppression, and registration restoration paths are covered by automated regression tests.
  • Finder owns default-folder window, tab, reuse, and Space behavior.
  • This release publishes the Direct notarized DMG only. MAS purchase/restore and App Store Connect evidence remain separate work.

Verification Scope

  • Default Option recording and explicit multi-modifier combinations
  • All supported punctuation keys, with Fn intentionally excluded
  • Recorder focus lifecycle, global-hotkey suspension, queued callback rejection, configuration changes during recording, and registration restoration
  • Retired managed Activity Monitor migration without deleting user bindings
  • Advanced Hotkeys Settings presentation, localization, and persistence
  • 28pt opening-mode icon layout
  • Focused regression suites, full 619 tests, swift build, production development packaging, localization linting, and git diff --check
