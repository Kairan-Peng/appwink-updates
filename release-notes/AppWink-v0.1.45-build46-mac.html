AppWink v0.1.45

更新

  • 修复热键窗口和设置窗口的红绿灯、窗口标题被页面内容遮住的问题。
  • 确保首次打开、调整窗口大小、切换设置子页及重新打开窗口后，原生标题栏仍位于内容上方。
  • 这是首个公开提供安装包的免费开源版本，无需试用、激活、许可证或登录；保留既有快捷键、文件书签和功能设置。

安装

从本版本的 GitHub Release 下载 universal .dmg，将 AppWink 拖入 Applications。 支持 macOS 14 或更新版本，以及 Apple Silicon 和 Intel。 安装包保留 Developer ID 签名、Apple 公证和现有 Sparkle 更新信任链。 旧用户升级后可检查系统辅助功能和登录项状态；无需清空本机配置。

验证范围

  • 新增两项 AppKit 回归测试，覆盖初次内容挂载、重新配置及调整窗口大小时的原生按钮命中和标题层级。
  • 本机独立 QA 检查热键窗口、设置窗口、设置子页返回、关闭重开、缩放及浅色/深色外观。
  • 完整构建、测试与 universal 打包验证；实际登录启动、多显示器和全部物理输入组合不属于本次窗口修复的验收结果。

English

  • Fixes native window controls and titles being covered by content in the hotkey and Settings windows.
  • Preserves titlebar ordering after initial attachment, resizing, Settings navigation and reopening.
  • First publicly distributed free GPL-3.0-or-later installer, retaining saved settings, Developer ID signing, Apple notarization and existing Sparkle update trust.

Download the universal DMG for macOS 14 or later from this release and drag AppWink to Applications.
